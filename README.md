# PromptMind - 大語言模型與參數優化 AI 顧問

> 智慧化 LLM 選擇與模型參數配置 Agent | 中央大學 AI Agent 課程專案

## 💡 專案簡介

**PromptMind** 是一款專為開發者、產品經理與 AI Agent 架構師設計的 **LLM 選型與參數調校 AI 助理**。本專案旨在解決在不同應用情境下選擇合適大語言模型（如 GPT-4, Claude, Gemini 等）的決策痛點，自動評估模型價格、回應速度、知識量與 context window，並精準調整 Temperature、Max Tokens 等關鍵參數，達到成本與精準度的最佳平衡。

---

## 🎯 解決問題與使用場景

### 1. 解決問題
* **模型選擇困難與成本過高**：各大模型價格與特性差異大，開發者常因誤用高價模型而造成 API 費用暴增。
* **生成結果不穩定**：缺乏對 Temperature 與 Context Window 等參數的調校經驗，導致 AI 輸出幻覺或回答不符長度預期。
* **小型/蒸餾模型應用門檻**：不清楚何時該採用輕量化或蒸餾模型，無法在反應速度與輸出品質間取得平衡。

### 2. 使用場景
* **模型費用與效能評估**：自動對比 Coze 與各大平台提供的模型（如免費額度、Token 計費機制），推薦最符合預算的 API 方案。
* **動態參數配置對話**：輸入應用場景（如文案創作或程式碼生成），Agent 自動推薦最佳的 Temperature 與 Context Window 參數組合。
* **模型蒸餾與輕量化建議**：評估任務複雜度，建議是否採用蒸餾模型替代大模型，實現低成本、高效率的 Agent 部署。
